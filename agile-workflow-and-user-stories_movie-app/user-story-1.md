## Acceptance Criteria

[ ] List scrolls vertically. <br>
[ ] Display a list of movie cards. <br>
[ ] Mobile View: min. two columns. <br>
[ ] If the fetch needs time implement a loading indicator. <br>
[ ] Each card contains a image (with alt-text), title and rating of the movie. <br>
([ ] if a image can't be found a placeholder image is shown.) <br>
